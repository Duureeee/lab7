## Дүгнэлт (Debrief)

Couch Potato Tour нь хамгийн үр дүнтэй аяллуудын нэг байсан бөгөөд BUG-01, BUG-02, BUG-03, BUG-06 согогуудыг илрүүлэхэд ашиглагдсан.

Saboteur Tour ашиглан BUG-08 буюу буруу JSON хүсэлтэд HTTP 200 OK буцааж байгаа API согогийг илрүүлсэн.

Хайлтын оролтын хувилбаруудыг шалгах үед BUG-07 буюу том, жижиг үсэг ялгадаг согог батлагдсан.

Charter-аас гадуурх нэмэлт шалгалтаар 2101 онтой номыг устгахад хамгийн шинэ он 2020 болж зөв шинэчлэгдэж байгааг ажигласан.

Энэ нь шинэ согог биш боловч системийн зөв ажиллаж буй нэг үйлдлийг баталгаажуулсан.

Хуучин хувилбарын холбоос болон API-ийн бүх боломжит оролтын хувилбарыг бүрэн шалгаж амжаагүй.

Дараагийн session-ийн charter-д эдгээр чиглэл болон олон хэрэглэгч зэрэг ажиллах үеийн ажиллагааг хамруулах нь зүйтэй.

Лаб 1-ийн Playwright автомат тестээр BUG-01, BUG-02, BUG-03, BUG-04, BUG-06, BUG-07, BUG-10 зэрэг согогуудыг тохирох шалгалтын нөхцөл бичсэн тохиолдолд илрүүлэх боломжтой байсан.

BUG-05 болон BUG-09 зэрэг визуал согогуудыг хүний нүдээр илрүүлэхэд хялбар боловч screenshot comparison аргаар автоматжуулж болох бөгөөд BUG-08-ыг API автомат тестээр илрүүлэх боломжтой.
