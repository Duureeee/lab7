# BUG-02: Зөвшөөрөгдөх хүрээнээс гадуурх онтой ном нэмэгдэж байна

**Орчин:** Уншлагын жагсаалт v2.0, Chrome, Ubuntu WSL2, 2026-10-20

**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. node app.js командаар серверийг шинээр ажиллуулна.
2. Браузераар http://localhost:3000 хаягийг нээнэ.
3. Гарчиг талбарт nom2 гэж бичнэ.
4. Зохиолч талбарт bi гэж бичнэ.
5. Он талбарт 2101 гэж бичнэ.
6. Нэмэх товчийг дарна.
7. Номын жагсаалтыг шалгана.

## Хүлээгдэж байсан үр дүн

Он нь 1000-2100 хоорондох бүхэл тоо байх ёстой.
2101 гэсэн онтой ном нэмэгдэхгүй, ойлгомжтой
алдааны мессеж харагдах ёстой.

## Бодит үр дүн

2101 онтой ном жагсаалтад амжилттай нэмэгдсэн.
Зөвшөөрөгдөх оны хязгаарын шалгалт ажиллахгүй байна.

## Ноцтой байдал

**Major** — Систем шаардлага хангахгүй онтой
номыг хүлээн авч, өгөгдлийн зөв байдлыг алдагдуулж байна.
