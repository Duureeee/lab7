# BUG-08: API буруу JSON өгөгдөлд HTTP 200 OK буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Ubuntu WSL2, Node.js v18.19.1, 2026-10-20

**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. Ubuntu терминал нээнэ.
2. cd ~/lab07 командаар төслийн хавтсанд орно.
3. node app.js командаар серверийг ажиллуулна.
4. Шинэ терминал нээнэ.
5. Дараах командыг ажиллуулна:

~~~bash
curl -i -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  --data 'буруу оролт'
~~~

## Хүлээгдэж байсан үр дүн

API буруу JSON өгөгдөлд HTTP 400 Bad Request статус буцаах ёстой.

## Бодит үр дүн

Сервер HTTP 200 OK статус болон дараах хариуг буцаасан:

~~~json
{"result":"OK"}
~~~

## Ноцтой байдал

**Major** — Буруу JSON өгөгдлийг алдаа гэж танихгүй, амжилттай хүсэлт мэт хариулж байна.
