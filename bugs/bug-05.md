# BUG-05: Устгах товч улаан биш, ногоон өнгөтэй байна

**Орчин:** Уншлагын жагсаалт v2.0, Chrome, Ubuntu WSL2, 2026-10-20

**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. node app.js командаар серверийг шинээр ажиллуулна.
2. Браузераар http://localhost:3000 хаягийг нээнэ.
3. Номын жагсаалтын хүснэгтийг харна.
4. Ном бүрийн хажууд байрлах Устгах товчийн өнгийг шалгана.

## Хүлээгдэж байсан үр дүн

Устгах нь өгөгдлийг арилгах аюултай үйлдэл тул
товч улаан өнгөтэй харагдах ёстой.

Энэ нь хэрэглэгчид устгах үйлдлийг бусад
үйлдлээс ялгахад тусална.

## Бодит үр дүн

Номын жагсаалт дахь Устгах товч ногоон
өнгөтэй харагдаж байна.

Энэ нь интерфейсийн өнгөний шаардлагыг
зөрчиж байна.

## Ноцтой байдал

**Cosmetic** — Устгах үйлдэл ажиллаж байгаа боловч
товчийн өнгө шаардлагад нийцэхгүй байна.
